<TLDR>A short, hands-on course: learn the idea, run the example, apply the rules.</TLDR>

This masterclass takes the team from "I can read a React component" to "I can design one that others enjoy using". Every lesson is short, has live examples you can edit in your own editor, and ends with rules we apply in our projects.

## Who it is for

- Developers new to React who know modern JavaScript.
- Developers who use React daily but want a shared vocabulary and shared rules.

## How the course is organised

| Section | What you learn |
| --- | --- |
| Foundations | JSX, components, props and rendering lists. |
| Hooks | `useState`, `useEffect`, `useRef`, `useContext`, `useReducer` and custom hooks. |
| Patterns | Composition, forms, data fetching, performance and React 19. |

## How to use each lesson

1. Read the idea, then run the **Preview** and open the **Code** tab.
2. Copy the example into a scratch project and change it.
3. Check the **Rules of thumb** at the end before you open a pull request.

<Callout variant="tip">
Every example in this site lives in `src/examples/`. Run the site locally with `npm run dev` to edit them and see the page update.
</Callout>

## What you need

- Node.js 20 or newer.
- A code editor with TypeScript support.
- Basic JavaScript: arrow functions, destructuring, `map` and `filter`, and modules.
